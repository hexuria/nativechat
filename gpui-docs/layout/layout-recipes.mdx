## Centered card

```rust
div()
    .size_full()
    .flex()
    .items_center()
    .justify_center()
    .bg(rgb(0x0f172a))
    .child(
        div()
            .w(px(420.))
            .rounded_2xl()
            .p_8()
            .gap_4()
            .flex()
            .flex_col()
            .bg(rgb(0x111827))
            .shadow_xl()
            .child("Title")
            .child("Body copy")
    )
```

## Split pane with resize handle

Pair this View with the `ui/src/components/resizable` helper in this repository.

```rust
Resizable::new()
    .direction(Axis::Horizontal)
    .min(px(180.))
    .initial_fraction(0.3)
    .left(|_| sidebar())
    .right(|_| editor())
```

## Toolbar with right-aligned actions

```rust
div()
    .flex()
    .items_center()
    .gap_3()
    .p_3()

    .child(div().text_sm().text_color(gpui::slate(300)).child("Project"))

    .child(primary_button("Deploy"))
```

## Chat column

```rust
div()
    .flex()
    .flex_col()
    .h_full()
    .child(
        div()
            .flex_1()
            .overflow_scroll()
            .gap_3()
            .p_4()
            .children(messages.iter().map(|message| chat_bubble(message)))
    )
    .child(
        div()
            .p_4()
            .bg(rgb(0x11131a))
            .rounded_t_2xl()
            .child(message_input())
    )
```

## Uniform list for logs

When every row has the same height, `uniform_list` avoids keeping thousands of DOM nodes alive.

```rust
let list = uniform_list(
    self.list_state.clone(),
    |row, _window, _cx| {
        div()
            .flex()
            .gap_3()
            .px_3()
            .py_2()
            .child(row.timestamp.clone())
            .child(row.message.clone())
            .into_any_element()
    },
);

div().child(list)
```
