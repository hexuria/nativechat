---
title: "Div"
description: "The all-purpose container for layout, styling, and interaction."
---

`div()` is GPUI’s swiss-army knife. It combines the `Styled` and `InteractiveElement` traits so you can build most UI without writing custom elements.

## Basic usage

```rust
div()
    .flex()
    .flex_col()
    .gap_2()
    .p_4()
    .rounded_xl()
    .bg(rgb(0x0f172a))
    .child("Title")
    .child("Supporting copy")
```

## Events

```rust
let increment = cx.listener(|counter: &mut Counter, _: &Increment, _window, cx| counter.increment(cx));

div()
    .hover(|card| card.bg(rgb(0x1f2937)))
    .on_click(|_event, _window, cx| cx.dispatch(Increment))
    .on_mouse_down(MouseButton::Left, |event, _window, _| {
        println!("Pressed at {:?}", event.position);
    })
    .on_action::<Increment>(increment)
    .child("Click me")
```

`div` supports capture/bubble listeners for mouse, keyboard, drag, and scroll. Use `cx.listener` to safely mutate your view from those callbacks.

## Hover states

```rust
div()
    .rounded_lg()
    .bg(rgb(0x111827))
    .hover(|card| card.bg(rgb(0x1f2937)))
    .child("Hover me")
```

## Tooltips & pointers

```rust
div()
    .tooltip(|window, cx| Tooltip::new("Copy").build(window, cx))
    .on_mouse_enter(|_, window, _| window.set_cursor_style(CursorStyle::PointingHand))
    .child(icon("copy"))
```

## Group styling

Parent elements can react when a child with the same group ID is hovered/active:

```rust
div()
    .group_hover("row", |style| style.bg(rgb(0x1a1d29)))
    .children(rows.iter().map(|row| {
        div()
            .group("row")
            .px_3()
            .py_2()
            .child(row.title.clone())
    }))
```

<Tip>
If you find yourself writing the same `div` chain repeatedly, wrap it in a function returning `impl IntoElement`. It keeps render methods short and makes it easier to enforce consistent spacing.
</Tip>
