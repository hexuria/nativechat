title: "Text input & IME"
description: "Implement `EntityInputHandler` so your views behave like native text fields."
---

[`input.rs`](https://github.com/zed-industries/zed/blob/main/crates/gpui/src/input.rs) bridges platform IME events with GPUI views. It gives you full control over selections, marked ranges, clipboard access, and hit testing.

## Architecture

1. **Views implement `EntityInputHandler`.** Each method mirrors [`InputHandler`] but receives your view state + `Window` context.
2. **Elements register the handler.** During paint call `window.handle_input(&focus_handle, ElementInputHandler::new(bounds, view_entity), cx)`.
3. **GPUI routes platform input.** As long as the focus handle is active, GPUI forwards composition, selection, and clipboard events to your view.

## Minimal example

```rust
use gpui::{App, Context, Element, ElementInputHandler, Entity, FocusHandle, SharedString, UTF16Selection, Window, div, prelude::*};
use std::ops::Range;

struct TextBox {
    focus: FocusHandle,
    content: SharedString,
    selection: Range<usize>,
}

impl EntityInputHandler for TextBox {
    fn text_for_range(
        &mut self,
        range: Range<usize>,
        actual: &mut Option<Range<usize>>,
        _window: &mut Window,
        _cx: &mut Context<Self>,
    ) -> Option<String> {
        actual.replace(range.clone());
        Some(self.content[range].to_string())
    }

    fn selected_text_range(
        &mut self,
        _ignore_disabled: bool,
        _window: &mut Window,
        _cx: &mut Context<Self>,
    ) -> Option<UTF16Selection> {
        Some(UTF16Selection::new(self.selection.clone(), false))
    }

    fn replace_text_in_range(
        &mut self,
        range: Option<Range<usize>>,
        new_text: &str,
        _window: &mut Window,
        cx: &mut Context<Self>,
    ) {
        let range = range.unwrap_or(self.selection.clone());
        self.content.replace_range(range.clone(), new_text);
        let caret = range.start + new_text.len();
        self.selection = caret..caret;
        cx.notify();
    }

    // implement the remaining methods (`bounds_for_range`, `character_index_for_point`, etc.)
}

struct TextElement {
    view: Entity<TextBox>,
}

impl Element for TextElement {
    type RequestLayoutState = (); // omitted for brevity
    type PrepaintState = ();

    fn paint(
        &mut self,
        _id: Option<&gpui::GlobalElementId>,
        _inspector_id: Option<&gpui::InspectorElementId>,
        bounds: gpui::Bounds<gpui::Pixels>,
        _layout: &mut Self::RequestLayoutState,
        _prepaint: &mut Self::PrepaintState,
        window: &mut Window,
        cx: &mut gpui::App,
    ) {
        let focus = self.view.read(cx).focus.clone();
        window.handle_input(&focus, ElementInputHandler::new(bounds, self.view.clone()), cx);
    }
}

impl Render for TextBox {
    fn render(&mut self, _window: &mut Window, cx: &mut Context<Self>) -> impl IntoElement {
        div().key_context("TextBox").track_focus(&self.focus).child(TextElement {
            view: cx.entity(),
        })
    }
}
```

See [`examples/input.rs`](https://github.com/zed-industries/zed/blob/main/crates/gpui/examples/input.rs) for a production-ready implementation that handles grapheme boundaries, mouse selection, clipboard commands, and IME composition.

## Required trait hooks

| Method | Purpose |
| --- | --- |
| `text_for_range` | Provide UTF-8 text for a UTF-16 range (used by the IME). |
| `selected_text_range` / `marked_text_range` | Communicate caret + active composition spans. |
| `replace_text_in_range` / `replace_and_mark_text_in_range` | Mutate the buffer with either committed text or IME drafts. |
| `bounds_for_range` | Return on-screen `Bounds<Pixels>` so the OS knows where to draw composition windows. |
| `character_index_for_point` | Hit test mouse clicks to a caret offset. |

## Tips

- Always operate on grapheme clusters (`unicode-segmentation`) to avoid splitting emoji or composed characters.
- Convert offsets between UTF-8 and UTF-16 when talking to the platform (`UTF16Selection` helpers are provided).
- Use `window.show_character_palette()` and clipboard helpers (`cx.write_to_clipboard`, `cx.read_from_clipboard`) to match native behavior.
- When the buffer changes call `cx.notify()` so GPUI rerenders and the IME sees fresh layout data.
